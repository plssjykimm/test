# Tiny Habit

Codex와 GitHub 작업 흐름을 연습하기 위한 작은 습관 체크 웹앱입니다. 습관과 완료 기록은 브라우저의 `localStorage`에 저장됩니다.

## 실행

```bash
npm start
```

브라우저에서 `http://localhost:8000`을 엽니다.

## 테스트

```bash
npm test
```

## 며칠간 연습할 변경 예시

1. 습관 삭제 전에 확인 메시지 추가
2. 최근 7일 달력 보기 추가
3. 다크 모드 추가
4. 기능별 브랜치를 만들고 GitHub Pull Request로 병합
